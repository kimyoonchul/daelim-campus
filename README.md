# 대림 캠퍼스 온라인

대림대학교 안양 캠퍼스를 3D로 걸어 다니며, 같은 시간에 들어온 사람들과 만나 채팅하는 웹 페이지입니다.
전산관(컴퓨터 계열 건물)을 조금 더 공들여 만들었고, 5층에는 지공모 · COMMON · 모비딕 동아리방이 있습니다.

- 바로 가기: https://kimyoonchul.github.io/daelim-campus/
- **대림대학교 공식 서비스가 아닌 동문 개인 프로젝트**입니다.

## 할 수 있는 것

| | |
|---|---|
| 걷기 | `WASD` 이동, `Shift` 달리기, `Space` 점프, 마우스 드래그로 시점, 휠로 확대·축소. 휴대폰은 왼쪽 스틱 + 화면 드래그 |
| 만나기 | 닉네임·학번·동아리·한마디를 적고 입장하면 다른 접속자에게 과잠 입은 캐릭터로 보입니다. `Enter`로 채팅, `1~6` 감정표현 |
| 스탬프 투어 | 건물 15곳의 안내판 앞 노란 원에 서면 스탬프. 다 모으면 학사모 |
| 등굣길 타임어택 | 정문 빨간 깃발에서 시작 → 꼭대기 수암관까지. 무빙워크를 타도 됩니다 |
| A+ 줍기 | 캠퍼스 곳곳에 떠 있는 A+ 동전 |
| 전산관 | 광장 쪽 입구로 들어가 4층 로비, 엘리베이터로 5층 동아리방. 지공모 퀴즈 · COMMON 아이템 뽑기 · 모비딕 스네이크 |
| 난투 모드 | `Q`로 무기를 들면(주먹 · 물총 · 폭죽 바주카 · 대포) 같은 모드인 사람끼리만 서로 맞습니다. 무기를 넣으면(평화) 무적. `F` 또는 클릭한 곳으로 발사, 휴대폰은 공격 버튼·화면 탭 |
| 건물 부수기 | 폭죽·대포로 건물을 무너뜨릴 수 있고, 45초 뒤 저절로 다시 지어집니다(막힌 길·문·스탬프는 그대로). 길가 주차 차도 터집니다 |
| 자동차 | 길가·주차장 차 옆에서 `E`로 타고 내립니다. `W/S` 가속·후진, `A/D` 방향, `Space` 브레이크, `F` 경적 |
| 보스 | 수암관 언덕의 **잔소리 대마왕**(확성기 머리), 운동장 동쪽의 **버그 마왕**(모니터 머리, 필살기 "신택스 에러!"). 무기를 들고 다가가면 깨어납니다. 운동장 서쪽 끝에는 연습 과녁 |
| 그 밖에 | 낮·노을·밤 전환, 운동장 축제 불꽃, 생활관 커피(체력 회복), 정문 안내 곰 |

진행 상황(스탬프·기록)은 각자의 브라우저에만 저장됩니다.

난투는 만화 같은 연출(물총 물보라, '펑!'·'와르르!' 글자)로 만들었고, 기절해도 보건실(임곡관) 앞에서 바로 깨어납니다. 두 보스는 **특정 인물을 본뜨지 않은 가상의 캐릭터**입니다.

## 알아 둘 점

- **접속자 정보와 채팅은 공개됩니다.** 서버 없이 동작하도록 가입이 필요 없는 공개 MQTT 브로커(`broker.emqx.io`, `test.mosquitto.org`, 예비 `mqtt-dashboard.com`)를 중계로 씁니다. 같은 주제를 구독하면 누구나 내용을 볼 수 있으므로 실명·연락처는 적지 마세요.
- **대화는 어디에도 저장되지 않습니다.** 같은 시간에 접속한 사람끼리만 보이고, 지난 대화·방명록은 없습니다.
- 공개 브로커는 시험용 무료 서비스라 가끔 느리거나 끊길 수 있습니다. 그때는 혼자 걷기로 계속되고 자동으로 다시 연결합니다. 안정적으로 쓰려면 `src/config.js`의 `NET.brokers`를 직접 운영하는 브로커 주소로 바꾸면 됩니다.
- 주소 끝에 `?room=이름`(영소문자·숫자 16자 이내)을 붙이면 그 주소를 아는 사람끼리만 만나는 방이 됩니다. 예: `…/daelim-campus/?room=mobidic08` (비밀번호가 아니라 이름만 다른 방이므로 내용이 암호화되지는 않습니다.)
- 받은 메시지는 형식·길이·좌표 범위를 검사하고, 보낸 사람별로 속도를 제한하며, 화면에는 항상 글자로만(`textContent`) 넣습니다. 접속자 목록에서 특정 사람의 채팅을 숨길 수 있습니다.
- 난투의 피해는 맞는 쪽 화면이 판정합니다. "맞혔다"는 주장이 오면 보낸 사람이 정말 무기를 들었는지, 사거리 안인지, 무기별 피해 상한과 1초당 횟수·피해 상한을 넘지 않는지 확인한 뒤에만 받습니다. 그래서 무기를 넣은(평화) 사람은 조작된 메시지로도 다치지 않습니다. 건물 붕괴는 각자 화면의 연출일 뿐 지형·충돌에는 영향이 없습니다.

## 무엇이 실제이고 무엇이 상상인가

| 항목 | 근거 |
|---|---|
| 건물 평면·도로·계단·무빙워크·주차장·운동장 위치 | OpenStreetMap |
| 건물 이름·기호(A~Y)·층별 안내 | 학교 공식 캠퍼스맵(2026년 11월 확인)의 사실 정보를 간추림 |
| 건물 색·창 모양·지붕 | 공식 안내 사진을 보고 직접 그린 절차적 텍스처(사진은 저장소에 없음) |
| 높낮이 | SRTM 고도는 큰 경사 방향만 참고하고, 건물별 단차는 사진을 보고 손으로 정함 → **실제와 다를 수 있음** |
| 전산관 실내 방 구성 | 4·5층에 있는 시설 종류는 공식 층별 안내를 따랐으나, **방 위치와 동아리방 배치는 상상** |
| 동아리 소개 | 학과 홈페이지의 전공동아리 안내를 요약 |

고치고 싶은 곳:

- 건물 높이(단차)·출입구 방향: `tools/campus-config.mjs` → `node tools/build-campus.mjs`
- 전산관 실내 지도(글자 한 칸 = 1m): `src/world/interior.js`의 `FLOORS`
- 건물 설명·동아리 소개·퀴즈 문항: `src/game/content.js`
- 건물 외벽 색·창 모양: `src/world/buildings.js`의 `FACADES`, `STYLE`

## 구조

빌드 과정이 없는 정적 사이트입니다. `main` 브랜치 루트를 GitHub Pages로 그대로 내보냅니다.

```
index.html, css/style.css
vendor/three.module.min.js      three.js 0.170.0 (MIT)
data/campus-data.js             자동 생성: 건물·도로·지형 격자
src/main.js                     진입점
src/core/                       렌더러·입력·난수·효과음
src/world/                      지형, 건물, 소품, 전산관 실내, 충돌
src/player/                     아바타, 내 캐릭터, 카메라
src/net/                        MQTT 클라이언트, 프로토콜, 다른 접속자 보간
src/game/                       스탬프·타임어택·미니게임·콘텐츠
src/mayhem/                     난투: 규칙·검증(rules), 무기, 건물 부수기(destruct), 자동차(vehicles·carstep), 보스(boss·boss-data), 효과(gfx)
src/ui/                         입장 폼·채팅·패널·미니맵·난투 HUD
tools/                          데이터 생성과 점검 도구
```

## 개발

```
node tools/serve.mjs 8137        # http://localhost:8137
node tools/check-syntax.mjs      # 문법·숨은 제어문자 점검
node tools/build-campus.mjs      # OSM + 고도 → data/campus-data.js
ROOM=test node tools/bot.mjs 40  # 시험용 두 번째 접속자(브라우저는 ?room=test 로 열 것)
node tools/spike-mqtt.mjs        # 공개 브로커 접속·지연 점검
node tools/test-mayhem.mjs       # 난투 규칙·검증·자동차 물리 시험
```

난투 봇: `ROOM=test WPN=2 HIT=any node tools/bot.mjs 60 물총봇` 처럼 환경변수를 주면 무기를 들고 공격하는 봇이 됩니다. `MODE=oversize|far|flood|peace`로 조작된 주장이 거부되는지 볼 수 있습니다(설명은 `tools/bot.mjs` 머리말).

`debug/map.html`은 생성된 지형·건물 데이터를 2D로 확인하는 페이지입니다.

GitHub Pages는 파일을 10분쯤 캐시합니다. 수정본이 바로 안 보이면 잠시 뒤 새로고침하세요.
